MJ Anatomy V15

Upload the CONTENTS of this folder to the root of your GitHub Pages repository:
  index.html
  models/

Do not rename the files inside models/.

V15 changes:
- Uses the real supplied GLB hierarchy.
- Fascia/bursa/tendon sheath/connective tissue are not treated as muscles.
- Nervous, cardiovascular and skin models load on demand when tapped.
- Artery/vein controls use cardiovascular hierarchy.
- Nerve/vessel/skin meshes can be selected and identified.
- Deterministic anatomical muscle depth mapping remains enabled.
- Right upper-limb joint engine retains constrained shoulder/scapula/clavicle coupling.
- visceral.glb is optional and is not included in this package.
